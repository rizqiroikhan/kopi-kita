# Kopi Kita

## Description

Kopi Kita is an application for recording and managing coffee-related information. It helps users organize coffee entries, track details, and keep their coffee data easy to access in one place.

## Features

- Record coffee entries and their details
- Manage and organize coffee data
- View a structured collection of saved coffee records
- Support a simple workflow for coffee tracking
